Folder ini disiapkan untuk frame kustommu yang ingin ditempel PERMANEN ke
dalam paket aplikasi Booth Nala (bukan cuma tersimpan di browser).

Cara pakainya:
1. Kirim file gambar frame (PNG transparan disarankan, ukuran sama dengan
   foto/kamera misalnya 960x540 atau rasio 16:9) ke saya lewat chat.
2. Saya akan taruh filenya di folder frames/ ini, dan mendaftarkannya ke
   dalam index.html (di bagian customFrames / BUILTIN_FRAMES) supaya
   otomatis muncul di semua pemilih frame — Kamera, Booth, dan Editor —
   bahkan saat file index.html ini dibuka pertama kali di perangkat lain.

Kalau kamu tidak sempat kirim file lewat chat, kamu tetap bisa menambah
frame langsung dari dalam aplikasinya sendiri:
  Tab "Frame" -> "Unggah frame" -> pilih gambar.
Frame yang diunggah lewat cara ini otomatis tersimpan di aplikasi dan tidak
perlu diunggah ulang tiap kali dibuka lagi di browser & perangkat yang sama.
