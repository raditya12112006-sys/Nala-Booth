Frame milikmu sendiri

Unggah gambar frame/bingkai (PNG transparan paling bagus). Sekali diunggah, frame otomatis muncul di semua pemilih frame (Kamera, Booth, Editor) dan tersimpan untuk sesi berikutnya.

Mau frame diambil otomatis dari folder frames/?
Browser tidak diizinkan membaca folder lokal komputer begitu saja (alasan keamanan), jadi frame kustom perlu masuk lewat tombol unggah di atas — tapi itu setara: sekali masuk, tersimpan permanen di aplikasi ini.

Kalau kamu ingin frame-frame itu ikut terpaket secara permanen di dalam file aplikasinya (bukan cuma tersimpan di browser), kirim saja file gambar frame-nya ke saya di chat — saya akan taruh di folder frames/ proyek ini dan daftarkan otomatis ke dalam kode, sehingga selalu ikut ada bahkan saat aplikasi dibuka pertama kali di perangkat lain.
